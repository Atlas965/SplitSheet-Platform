MASTER IMPLEMENTATION PROMPT — SPLITSHEET RIGHTS LEDGER (ARCHIVE / REMOVE ASSET SYSTEM)

ROLE:
You are a senior full-stack fintech architect, security engineer, and product designer. Build this feature for SplitSheet as production-grade software using best practices in React, TypeScript, Node.js, PostgreSQL, Drizzle ORM, Tailwind CSS, and secure audit-log architecture.

PROJECT CONTEXT:
SplitSheet is a music fintech platform for agreements, ownership splits, royalty tracking, and collaborator payouts.

We are building a “Rights Ledger” dashboard where creators, producers, managers, and labels manage music assets (songs, masters, compositions, agreements).

GOAL:
Implement a secure Asset Management system inside the Rights Ledger that allows users to remove assets from active use WITHOUT destroying legal, financial, or ownership history.

IMPORTANT:
Do NOT implement dangerous hard-delete logic for signed agreements, ownership records, payouts, or revenue history.

Instead, build enterprise-grade controls:
1. Archive Asset
2. Deactivate Asset
3. Transfer Ownership
4. Revoke Collaborator Access
5. Delete Draft Asset (only unsigned/unpublished drafts)
6. Immutable Audit Trail

====================================================
PHASE 3 — ARCHIVE SYSTEM (RECOMMENDED)
====================================================

When user clicks Archive Asset:

Modal:
Title: Archive Asset?
Body:
This removes the asset from active dashboards while preserving ownership, payout, and legal records.

Buttons:
- Cancel
- Archive Asset

Backend behavior:
- status = archived
- archivedAt = now()
- archivedBy = currentUser.id
- create activity log

Archived assets:
- Hidden from normal dashboard
- Visible in “Archived Assets” tab
- Can be restored

====================================================
PHASE 4 — DEACTIVATE SYSTEM
====================================================

Purpose:
Pause payouts, royalties, and new transactions temporarily.

Behavior:
- status = deactivated
- prevent new revenue entries
- prevent payout runs
- preserve all history

====================================================
PHASE 5 — DELETE DRAFT SYSTEM
====================================================

Only allowed if ALL true:

- No signatures
- No collaborators accepted
- No revenue records
- No ownership ledger finalized
- Status = draft

Then:
soft delete only

deletedAt = now()

Never permanently delete from DB.
